Your website is about to be read mostly by machines.

The old bargain was simple: a crawler took your content, search sent you a human, you monetised the attention. That breaks the moment an agent reads the page, answers the question, and the visit never happens.

Point this at any URL. It fetches the page the way an AI crawler actually sees it, audits 45+ weighted signals across three lenses, generates the markup and copy blocks that fix what it found — and then tells you, item by item, what no generated file can fix.

Three lenses, one fetch

Each check reports what it found, why it matters and what to do — and carries a weight, so the 0–100 score reflects impact rather than check count.

SEO

Crawl, index, rank

Titles, canonicals, the robots.txt verdict for Googlebot on this path, sitemap discovery, Open Graph, redirect chains, heading order, alt coverage, structured-data validity, render-blocking scripts, hreflang.

AEO

Be the answer

FAQ and HowTo markup, question-phrased headings and whether a direct answer follows each one, answer-first openings, TL;DR blocks, readability, paragraph chunking, speakable markup — and sentences that lose their meaning the moment they are extracted.

GEO

Get cited by name

Per-vendor AI crawler access, /llms.txt, entity identity and sameAs, named authorship, freshness, statistics density, sourced claims, quotable statements, original-research signals, server-rendered content, retrieval chunk sizing.

The fetch is a plain HTTP request with no JavaScript execution — deliberately, because that is what most AI crawlers see. A low word count here is a real finding, not a limitation of the tool.

And what it refuses to write

the part that makes this a mandate rather than a download

The files are the floor, not the ceiling. Machine-readability takes an afternoon. Being worth citing takes a quarter.

Every failing check is routed into exactly one of two buckets: one a generated file closes, and one that needs a person. Nothing is quietly counted as done. A generated file whose prerequisite is not met ships with the blocker attached rather than pretending to be finished.

1 — Closed by the files

The finding, the file that fixes it, and exactly where it goes. Paste it and the finding goes away. This is the fast half — and the half that gets mistaken for the whole job.

Page: https://developer.mozilla.org/en-US/docs/Web/HTML
Scores: SEO 85 · AEO 57 · GEO 52 (overall 65, grade D)

20 open findings. 11 close with a file in this pack. 9 need a person.
32 sentences in the generated files are marked TODO on purpose.

## 1 — Closed by the generated files

- [ ] Entity identity (Organization/Person) → `schema-graph.html`
  - Now: No Organization or Person schema
  - Where: Already in the @graph as the Organization node.
  - ⚠ Blocked: No sameAs profiles. Without Wikipedia, LinkedIn, Crunchbase
    or GitHub URLs, the Organization node names an entity no model can resolve.

## 3 — Still yours

- [ ] Quantitative claims — Research, ~days (GEO, failing, high impact)
  - Now: 0 statistics (0.0 per 1,000 words) · 2 numbers total
  - Do: Concrete figures are what generative engines lift. Add percentages,
    sample sizes and dated benchmarks — each with its source.
  - Why we cannot do it for you: Models quote numbers. We will not invent them,
    and a fabricated statistic is the single fastest way to lose a citation
    permanently.

- [ ] Original data or research — Leadership, ~weeks (GEO, weak, medium impact)
  - Why we cannot do it for you: Original data is the only durable reason for a
    model to name you rather than paraphrase you. It is the biggest item on this
    list and the only one no competitor can copy.

Run it

one dependency, no build step, nothing leaves your machine except the page fetch

git clone https://github.com/avantigroupai/aeo-geo-seo-generator.git
cd aeo-geo-seo-generator
npm install && npm start

Then open http://localhost:4321 and paste a URL.

This page is documentation, not the live tool. The audit fetches third-party URLs server-side — with a redirect chain tracker and an SSRF guard — which a static site cannot do from a browser. Run it locally, or host server.js anywhere Node runs.
